# Praktikum 2 - HTML Lanjutan

## Deskripsi
Praktikum ini mempelajari penggunaan tabel, form, semantic HTML,
multimedia, dan validasi form dasar menggunakan HTML.

## Langkah Praktikum
1. Membuat tabel data mahasiswa.
2. Mengembangkan tabel menggunakan thead, tbody, dan tfoot.
3. Membuat form registrasi mahasiswa.
4. Membuat radio button dan checkbox.
5. Membuat select dan textarea.
6. Menerapkan validasi form dasar.
7. Membuat halaman Semantic HTML.
8. Menambahkan multimedia audio dan video.
9. Membuat proyek mini Form Biodata Mahasiswa.

## Hasil Praktikum
- Tabel data mahasiswa.
- Form registrasi dan form biodata.
- Halaman Semantic HTML.
- Elemen multimedia.
- Validasi form menggunakan atribut HTML.
